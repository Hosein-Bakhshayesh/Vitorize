# راه‌اندازی آسانک در ویتورایز

مسیر تنظیمات: **پنل ادمین ← تنظیمات ← اعلان‌ها**

فقط این مقادیر را وارد کنید:

- `Sms.AsanakUsername`: نام کاربری وب‌سرویس آسانک
- `Sms.AsanakPassword`: رمز وب‌سرویس آسانک
- `Sms.AsanakSource`: شماره مبدأ فعال آسانک؛ برای پیامک متنی آزاد ضروری است
- `Sms.OtpTemplateId`: شناسه قالب OTP آسانک

ویتورایز فقط از آسانک استفاده می‌کند و گزینه‌ای برای انتخاب Provider یا واردکردن API Key/خط SMS.ir ندارد.

برای OTP، مقادیر قالب به ترتیب `CODE` و سپس `EXPIRE` ارسال می‌شوند. تمام اطلاع‌رسانی‌های سفارش، کیف پول، تیکت، احراز هویت و مدیر متن آزادِ متعلق به برنامه‌اند و از شماره مبدأ آسانک و صف پایدار ارسال می‌شوند. شناسه قالب OTP هرگز در کد هاردکد نمی‌شود.

پس از واردکردن اطلاعات، از مسیر **مدیریت پیامک ← آزمایش و عیب‌یابی** قالب OTP را آزمایش کنید. ارسال واقعیِ متن آزاد را فقط با شماره آزمایشی و پس از تأیید اپراتور انجام دهید.
