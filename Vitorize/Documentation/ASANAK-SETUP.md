# راه‌اندازی آسانک در ویتورایز

مسیر تنظیمات: **پنل ادمین ← تنظیمات ← اعلان‌ها**

فقط این مقادیر را وارد کنید:

- `Sms.AsanakUsername`: نام کاربری وب‌سرویس آسانک
- `Sms.AsanakPassword`: رمز وب‌سرویس آسانک
- `Sms.AsanakSource`: شماره مبدأ فعال آسانک؛ برای همهٔ پیامک‌ها ضروری است

ویتورایز فقط از آسانک استفاده می‌کند و گزینه‌ای برای انتخاب Provider یا واردکردن API Key/خط SMS.ir ندارد.

OTP و تمام اطلاع‌رسانی‌های سفارش، کیف پول، تیکت، احراز هویت و مدیر متن آزادِ متعلق به برنامه‌اند و از شماره مبدأ آسانک ارسال می‌شوند. OTP شامل کد، زمان اعتبار و فوتر استاندارد ویتورایز است؛ کد در تاریخچه یا لاگ ذخیره نمی‌شود.

پس از واردکردن اطلاعات، از مسیر **مدیریت پیامک ← آزمایش و عیب‌یابی** یک OTP متنی را با شماره آزمایشی بررسی کنید.
