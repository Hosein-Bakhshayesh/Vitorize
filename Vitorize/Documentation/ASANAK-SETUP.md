# راه‌اندازی آسانک در ویتورایز

مسیر تنظیمات: **پنل ادمین ← تنظیمات ← اعلان‌ها**

فقط این مقادیر را وارد کنید:

- `Sms.AsanakUsername`: نام کاربری وب‌سرویس آسانک
- `Sms.AsanakPassword`: رمز وب‌سرویس آسانک
- `Sms.AsanakSource`: شماره مبدأ فعال آسانک؛ برای پیامک متنی آزاد ضروری است
- `Sms.OtpTemplateId`: شناسه قالب OTP آسانک
- `Sms.NotificationTemplateId`: شناسه قالب اطلاع‌رسانی آسانک

ویتورایز فقط از آسانک استفاده می‌کند و گزینه‌ای برای انتخاب Provider یا واردکردن API Key/خط SMS.ir ندارد.

برای OTP، مقادیر قالب به ترتیب `CODE` و سپس `EXPIRE` ارسال می‌شوند. برای اطلاع‌رسانی، تنها مقدار `ORDER_NUMBER` ارسال می‌شود. شناسه‌های قالب هرگز در کد هاردکد نمی‌شوند.

پس از واردکردن اطلاعات، از مسیر **مدیریت پیامک ← آزمایش و عیب‌یابی** یک قالب OTP و یک قالب اطلاع‌رسانی را آزمایش کنید.
