# نصب سریع در Plesk

1. دیتابیس قبلاً باید تأیید شده باشد.
2. در File Manager دامنه api.hbakhshayesh.ir، فایل‌های برنامه قدیمی را جایگزین کنید؛ اگر App_Data دادهٔ واقعی دارد آن را حذف نکنید.
3. فایل Vitorize.Api.Plesk.zip را همان‌جا آپلود و Extract کنید.
4. به پوشهٔ App_Data دسترسی نوشتن بدهید و برنامه را Restart کنید.
5. آدرس https://api.hbakhshayesh.ir/api/health/live و سپس /api/health/ready را بررسی کنید.
6. در File Manager دامنه hbakhshayesh.ir، فایل Vitorize.Web.Plesk.zip را آپلود و Extract کنید.
7. برنامهٔ Web را Restart کنید، سایت را باز کنید و با حساب مدیر وارد شوید.

هیچ فایل تنظیمات، web.config، متغیر محیطی، مسیر فیزیکی، URL یا Connection String را ویرایش نکنید.
